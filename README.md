# Agent Sentinel

Real-time monitoring and control dashboard for AI agents.

## What It Does
- Receives logs from AI agents via REST API
- Detects anomalies (loops, silent failures)
- Provides a kill switch to pause misbehaving agents
- Live dashboard with charts and alerts

## Tech Stack
- FastAPI (Python)
- SQLite
- HTML/CSS/JavaScript
- Chart.js
